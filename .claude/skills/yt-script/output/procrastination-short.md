# 60-Second Short: Why You Procrastinate on Things You Actually Want to Do

**Status:** Locked — ready to record.

## Hook (scored 71/100, WORKABLE — formula: The Deadline)
> You almost started this 3 times this year and quit before the 10-minute mark every single time.

## Full script (~155 words, ~62 sec @ 150wpm)

**[0:00–0:08] HOOK**
> You almost started this 3 times this year and quit before the 10-minute mark every single time.
`[ON SCREEN: text overlay counting "3" as you say it, cut on each number]`

**[0:08–0:18] THE TURN**
> That's not laziness. That's your brain treating excitement the same way it treats danger — so the second it gets real, you bail. Here's the actual fix.
`[ON SCREEN: cut to a close, direct-to-camera shot — no b-roll yet, this line needs to land]`

**[0:18–0:38] THE BODY**
> You don't need motivation. You need to shrink the start. Not "work on the project" — "open the file." Not "write the script" — "write one sentence." The 10-minute wall only exists because the task in your head is way bigger than the task in front of you.
`[ON SCREEN: split-screen — vague task ("work on project") vs. shrunk task ("open the file"), text punching in]`

**[0:38–0:52] THE PAYOFF**
> Set a timer for 10 minutes. Not to finish — just to not quit before it rings. That's the whole move. Momentum shows up after the start, never before it.
`[ON SCREEN: visible timer running down, 10:00 → 0:00]`

**[0:52–1:00] THE CLOSE**
> Try it on the thing you've quit on 3 times. One ask: comment the task you're avoiding.
`[ON SCREEN: comment box mockup / text prompt]`
